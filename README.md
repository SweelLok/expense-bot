# Expense Tracker Bot

Telegram-бот для учёта расходов и доходов с месячным планом по категориям.

## Функционал

- 💰 Доходы (зарплата/стипендия и т.п.) отдельной сущностью: приход денег не путается с тратами
- 🎯 Месячный план: бот сам считает, сколько можно тратить по каждой категории
- 📋 Подписки и другие регулярные платежи (раз в месяц / 2 / 3 / 6 / 12 месяцев, дробный период) с привязкой к категории — добавил, изменил или удалил платёж → план и остатки пересчитываются сразу
- ⚠️ Предупреждение, когда в категории осталось мало денег (порог настраивается, по умолчанию 7€)
- 💶 Баланс в EUR (просмотр и изменение)
- ➕ Запись трат (сумма, категория, описание, дата)
- 📊 Статистика за неделю/месяц/год/все (доход, расход, разница)
- ✏️ Редактирование и удаление трат
- 💱 Конвертация валют (EUR/USD/UAH)
- 📤 Экспорт в CSV
- 📝 Добавление своих категорий
- 📅 Возможность указать прошлую дату

## Как считается план месяца

    1. База месяца — от чего считать, задаётся в настройках (/setmode):
       • «деньги в наличии» (по умолчанию) — баланс + потрачено с 1-го числа.
         Доход на план не влияет, и трата базу не уменьшает.
       • «доход этого месяца» — фактические доходы, иначе плановый доход, иначе баланс.
       • «бюджет месяца» — фиксированная сумма из настроек (/setbudget).
    2. Из базы вычитаются все регулярные платежи (в пересчёте на месяц: 180€ раз в 2 месяца = 90€/мес).
    3. План категории = её регулярные платежи + её фикс-план (если задан). Лимиты от базы не зависят:
       сколько бы денег ни было, «еда» остаётся 100€.
    4. Категории без того и другого — «авто»: делят остаток поровну. «Резерв» — авто, поэтому весь
       излишек уходит туда. Если план больше базы — «план не сходится: не хватает N€».

Показатели категории: траты с 1-го числа / план / остаток / сколько это в день до конца месяца.

## Команды

| Команда | Описание |
|---------|----------|
| /start | Главное меню |
| /income 350 стипендия 01.10 | Быстро добавить доход (без аргументов — пошагово) |
| /budget | План на месяц по категориям |
| /setmode | От чего считать план: деньги в наличии / доход этого месяца / бюджет месяца |
| /setbudget 350 | Фиксированный бюджет месяца (режим «бюджет месяца») |
| /setplan 350 | Плановый доход месяца (режим «доход этого месяца») |
| /setwarn 7 | Порог предупреждения о заканчивающейся категории |
| /help | Справка |
| /cancel | Отменить текущее действие |

Кнопки меню: 💶 Баланс, 🎯 Бюджет, ➕ Добавить трату, 💰 Добавить доход, 📊 Статистика, 📋 Подписки,
✏️ Редактировать, 🗑 Удалить (трату или доход), ⚙️ Настройки.

В настройках: баланс, плановый доход, месячные планы категорий (число / 0 / «авто»), порог
предупреждения, свои категории, курсы, экспорт, очистка чата.

## Установка и запуск

```bash
cd expense-bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# Впиши BOT_TOKEN в .env (файла-примера в репозитории нет — создай сам)
python bot.py
```

База: путь берётся из `DB_PATH`, иначе файл `expenses.db` рядом с `db.py`.
Старые базы обновляются автоматически при старте (добавляются новые таблицы и колонки).

Тесты (без телеграма, сеть не нужна):

```bash
./venv/bin/python scripts/selftest.py       # бюджет, БД, миграции — 48 проверок
./venv/bin/python scripts/handler_test.py   # прогон хендлеров бота с подменой Bot — 34 проверки
./venv/bin/python scripts/seed_plan.py      # собрать чистую базу с настроенным планом
```
