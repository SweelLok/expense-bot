# Expense Tracker Bot

Telegram-бот для учёта расходов.

## Функционал

- 💶 Баланс в EUR (просмотр и изменение)
- ➕ Запись трат (сумма, категория, описание, дата)
- 📊 Статистика за неделю/месяц/год/все
- 📋 Управление подписками
- ⚠️ Лимиты по категориям с уведомлениями
- ✏️ Редактирование и удаление последней траты
- 💱 Конвертация валют (EUR/USD/UAH)
- 📤 Экспорт в CSV
- 📝 Добавление своих категорий
- 📅 Возможность указать прошлую дату для траты

## Команды

| Команда | Описание |
|---------|----------|
| /start | Главное меню |
| /balance | Показать баланс |
| /setbalance <сумма> | Установить баланс |
| /add | Добавить трату (пошагово) |
| /add <сумма> [валюта] <категория> [дата] [описание] | Быстрое добавление |
| /edit | Изменить последнюю трату |
| /delete | Удалить последнюю трату |
| /stats | Статистика |
| /all [страница] | Все траты |
| /subs | Подписки |
| /setlimit | Установить недельный лимит |
| /addcat | Добавить категорию |
| /export | Экспорт в CSV |
| /rates | Курсы валют |

## Установка и запуск

```bash
cd expense-bot
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Впиши BOT_TOKEN в .env
python bot.py
```
